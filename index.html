iPhone / iPad Safari 添加步骤：

1. 点击屏幕底部中间的 「分享」按钮 (□↑)
2. 向上滑动菜单，选择 「添加到主屏幕」
3. 点击右上角 「添加」 即可在桌面生成独立图标

Android 安卓 Chrome / Edge / 夸克添加步骤：

1. 点击浏览器右上角或底部的 「菜单 (⋮ 或 ≡)」
2. 选择 「添加到主屏幕」 或 「安装应用」

提示：需在 HTTPS 网址下打开才可永久离线
